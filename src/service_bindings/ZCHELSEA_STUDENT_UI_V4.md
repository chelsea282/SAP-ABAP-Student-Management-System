
# SAP RAP OData V4 Service Binding

## Service Binding
ZCHELSEA_STUDENT_UI_V4

## Binding Type
OData V4 - UI

## Service Definition
ZCHELSEA_STUDENT_RAP_SRV

## Service Version
1.0.0

## Publication Status
Published

## Exposed Entity Sets
- Students
- Courses
- Enrollments
- Marks
- Results

## Purpose
This service binding publishes the Student Management
System RAP service using OData V4.

It enables SAP Fiori Elements to access the Students,
Courses, Enrollments, Marks, and Results entities.

## Development Environment
- SAP BTP ABAP Environment
- Eclipse ADT
- ABAP RESTful Application Programming Model (RAP)

## Note
The service binding is an SAP repository configuration
object. This Markdown file documents its configuration;
it is not a deployable service binding artifact.
